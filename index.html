Backup & restore

CSV Excel में खोलने के लिए है। JSON में entries और settings दोनों सुरक्षित होते हैं; डेटा बदलकर फिर JSON upload करने पर restore किया जा सकता है। Restore मौजूदा data को replace करेगा।

Data & privacy

यह शुरुआती offline-first web app है। रिकॉर्ड इसी browser/device में सेव होते हैं; browser data साफ करने या app uninstall/website data हटाने से पहले JSON backup डाउनलोड करें। बैंक से automatic sync या पैसे का automatic transfer नहीं होता।
